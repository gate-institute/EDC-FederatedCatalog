# EDC FederatedCatalog

This is a fork of the [EDC FederatedCatalog](https://github.com/eclipse-edc/FederatedCatalog)
repo and contains gate-specific changes for testing and deployment purposes.

The `gate/0.12.0` branch is the main branch used for GATE deployments.
It contains changes to EDC's `v0.12.0` tag
(ref. [4c91e83](https://github.com/eclipse-edc/FederatedCatalog/tree/2a62275bac621d33a672afc58671bdee51e946f7)),
most of which are gate-specific changes inherited from the EDC Connector
(listed [here](https://github.com/gate-institute/EDC-Connector)).

For a detailed view of *all* changes, see the
[diff](https://github.com/gate-institute/EDC-FederatedCatalog/compare/v0.12.0...gate/0.12.0?expand=1).

## Quick start

Please refer to Eclipse's
[Quick Start](https://github.com/eclipse-edc/FederatedCatalog/tree/v0.12.0?tab=readme-ov-file#quick-start)
guide for FederatedCatalog.
